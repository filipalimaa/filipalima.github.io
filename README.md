# Filipa Lima — Personal Portfolio

Personal website built to showcase my move from Chemical Engineering into Software
Engineering — my background, projects, skills, and a bit of who I am outside of work.

**Live site:** https://filipalimaa.github.io/

## Pages

- `index.html` — Home
- `about.html` — About me: career story, my dog Constança, foster dogs, travel
- `resume.html` — Work experience & education timeline, with a downloadable CV
- `skills.html` — Technical skills
- `projects.html` — Projects built at Prio Energy
- `contact.html` — Contact details

## Structure

- `style.css` — shared stylesheet for all pages
- `script.js` — mobile navigation toggle
- `assets/` — CV (PDF) and photos used across the site

## Tech

Plain HTML, CSS and vanilla JavaScript — no build step, hosted on GitHub Pages.

## Running locally

Open any `.html` file directly in a browser, or serve the folder locally, e.g.:

```
python3 -m http.server
```

then visit `http://localhost:8000`.
